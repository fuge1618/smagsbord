# Smagsbord

Recetas de familia. By fuge1618.

App web para guardar recetas en un formato fijo y cocinarlas paso a paso desde una tablet o un celular.

- `index.html`: la app completa, en un solo archivo.
- `fotos/`: fotos de ejemplo, de Wikimedia Commons. Los créditos están en la app, en Configuración.

Es un proyecto familiar, sin fines comerciales.
